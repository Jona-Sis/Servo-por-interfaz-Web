# Nombre del proyecto
Control de servomotor por interfaz web

## Descripción
El objetivo de esta practica consiste en alojar un servidor web en el microcontrolador donde nos permita modificar
el gradó del servomotor en tiempo real


## Objetivos 
- Alojar una pagina web en el Arduino UNO R4 WIFI
- Pagina web funcional
- Movimiento en tiempo real de la página web al servomotor

## Material utilizado
- Arduino Uno R4 WiFi
- Servomotor
